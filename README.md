# MOPH Open Data Explorer

เว็บหน้าเดียว (ไฟล์ `index.html` ไฟล์เดียว) สำหรับค้นหา ดึง และดูข้อมูลสุขภาพจาก
[MOPH Open Data](https://opendata.moph.go.th/th/services/summary-table) ของกระทรวงสาธารณสุข
ไม่ต้องติดตั้งอะไร ไม่ต้องมี backend แค่เปิดไฟล์ในเบราว์เซอร์

> โปรเจกต์นี้เป็นเครื่องมือเสริมที่ผู้ใช้ทำขึ้นเอง ไม่ใช่ผลิตภัณฑ์อย่างเป็นทางการของกระทรวงสาธารณสุข
> ข้อมูลทั้งหมดเป็นของผู้ให้บริการต้นทาง กรุณาตรวจสอบเงื่อนไขการใช้ข้อมูลที่เว็บไซต์ MOPH Open Data

## ความสามารถ

- **แคตตาล็อกรายงานครบทุกรายการ** จากหน้า Summary Table (5 หมวดหลัก, 45 หมวดย่อย, ประมาณ 1,200 รายงาน) ดึงสดจาก API ไม่ต้องอัปเดตรายการเอง
  - ค้นหาตามชื่อตารางหรือชื่อรายงาน, กรองตามหมวดหมู่, ซ่อนรายงานที่ปิดแล้ว
  - ★ รายการโปรด และรายการใช้ล่าสุด (เก็บในเบราว์เซอร์ของผู้ใช้)
- **ดึงข้อมูลรายงาน** เลือกตาราง ปี พ.ศ. (แสดงเฉพาะปีที่มีข้อมูลจริงของตารางนั้น) และจังหวัด (ครบ 77 จังหวัด)
  - ตัวเลือกเพิ่มเติม: `limit`, `offset` และโหมดดึงทุกหน้าอัตโนมัติ
- **โครงสร้างตาราง** ชื่อคอลัมน์ ชนิดข้อมูล NULL ได้หรือไม่ และคำอธิบายภาษาไทย พร้อมคัดลอกเป็น `CREATE TABLE` หรือส่งออก CSV
- **ตารางข้อมูล** ค้นหา เรียงลำดับ แบ่งหน้า เอาเมาส์ชี้หัวคอลัมน์เพื่อดูคำอธิบาย
- **แผนภูมิ** สรุปความถี่ของค่าในคอลัมน์ที่เลือก
- **ส่งออก** CSV (รองรับภาษาไทยใน Excel) และ JSON
- **โค้ดตัวอย่าง** JavaScript, Node.js, PHP, Python, cURL ปรับตามค่าที่เลือกในฟอร์มอัตโนมัติ
- โหมดมืด/สว่าง และรองรับหน้าจอมือถือ

## วิธีใช้งาน

1. เปิด `index.html` ด้วย Chrome / Edge / Firefox (ต้องต่ออินเทอร์เน็ต)
2. เลือกรายงานจากการ์ดด้านล่าง หรือพิมพ์ชื่อตารางในช่อง `ตาราง` เช่น `s_ttm4`
3. เลือกปีและจังหวัด แล้วกด **ดึงข้อมูล**
4. ดูผลในแท็บ ตารางข้อมูล / โครงสร้างตาราง / แผนภูมิ / โค้ดตัวอย่าง

ลัด: กด `/` เพื่อพิมพ์ค้นหารายงานทันที

## เผยแพร่บน GitHub Pages

1. อัปโหลดไฟล์ `index.html` และ `README.md` ขึ้น repository
2. ไปที่ **Settings → Pages**
3. เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` และกด Save
4. รอสักครู่ จะได้ลิงก์รูปแบบ `https://<username>.github.io/<repository>/`

## API ที่เรียกใช้

| ใช้ทำอะไร | Method | Endpoint |
|---|---|---|
| รายการหมวดหมู่ย่อย | GET | `https://opendata.moph.go.th/opendata_api/reports/categories` |
| รายงานในหมวดย่อย | GET | `https://opendata.moph.go.th/opendata_api/reports/categorie/by-category-id/{cat_id}` |
| ปีที่มีข้อมูล | GET | `https://opendata.moph.go.th/api/report_year/{tableName}` |
| โครงสร้างตาราง | GET | `https://opendata.moph.go.th/api/report_schema/{tableName}` |
| ข้อมูลรายงาน | POST | `https://opendata.moph.go.th/api/report_data` |

ตัวอย่างการดึงข้อมูล:

```bash
curl -X POST "https://opendata.moph.go.th/api/report_data" \
  -H "Content-Type: application/json" \
  -d '{"tableName":"s_ttm4","year":"2568","province":"36","type":"json"}'
```

## ข้อควรรู้

- **Rate limit:** API จำกัดจำนวนครั้งที่เรียกต่อช่วงเวลา (ตอบ HTTP 429 เมื่อถี่เกินไป) หน้าเว็บจะรอและลองใหม่ให้เอง การโหลดรายการครั้งแรกจึงใช้เวลาราวครึ่งนาที
- **แคช:** รายการรายงานถูกเก็บใน `localStorage` ของเบราว์เซอร์ ครั้งต่อไปเปิดได้ทันที ล้างข้อมูลเว็บไซต์ของเบราว์เซอร์เพื่อโหลดใหม่
- **CORS / เครือข่าย:** ถ้าดึงข้อมูลไม่ได้ หน้าเว็บจะแสดงข้อความผิดพลาดและปุ่มข้อมูลตัวอย่าง (Demo) ไว้ดูการทำงาน ข้อมูล Demo ไม่ใช่ข้อมูลจริง
- **พารามิเตอร์ต่างกันตามรายงาน:** ฟอร์มส่ง `tableName`, `year`, `province` เป็นหลัก บางรายงานอาจต้องการพารามิเตอร์อื่นหรือไม่มีข้อมูลในบางปี/จังหวัด
- **รายงานที่ปิดแล้ว:** บางรายการในแคตตาล็อกมีข้อความ "ปิดรายงาน" อาจดึงข้อมูลไม่ได้ ใช้สวิตช์ "ซ่อนรายงานที่ปิด" เพื่อกรองออก
