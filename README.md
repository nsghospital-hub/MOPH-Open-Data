# MOPH Open Data Explorer

เว็บหน้าเดียว (ไฟล์ `index.html` ไฟล์เดียว) สำหรับค้นหา ดึง และดูข้อมูลสุขภาพจาก
[MOPH Open Data](https://opendata.moph.go.th/th/services/summary-table) ของกระทรวงสาธารณสุข
ไม่ต้องติดตั้งอะไร ไม่ต้องมี backend แค่เปิดไฟล์ในเบราว์เซอร์

> โปรเจกต์นี้เป็นเครื่องมือเสริมที่ผู้ใช้ทำขึ้นเอง ไม่ใช่ผลิตภัณฑ์อย่างเป็นทางการของกระทรวงสาธารณสุข
> ข้อมูลทั้งหมดเป็นของผู้ให้บริการต้นทาง กรุณาตรวจสอบเงื่อนไขการใช้ข้อมูลที่เว็บไซต์ MOPH Open Data

## ความสามารถ

- **แคตตาล็อกรายงานครบทุกรายการ** จากหน้า Summary Table (5 หมวดหลัก, 45 หมวดย่อย, ประมาณ 1,200 รายงาน) ดึงสดจาก API ไม่ต้องอัปเดตรายการเอง
  - ค้นหาตามชื่อตารางหรือชื่อรายงาน, กรองตามหมวดหมู่, ซ่อนรายงานที่ปิดแล้ว
  - ★ รายการโปรด และรายการใช้ล่าสุด (เก็บในเบราว์เซอร์ของผู้ใช้)
- **NCD Clinic Plus (13 ตัวชี้วัด)** อ้างอิงรายการตัวชี้วัดจาก [HDC](https://hdc.moph.go.th/cpm/public/kpi/9/2026) กดสลับมุมมองที่ปุ่ม "NCD Clinic Plus" เลือกปีงบประมาณ (2565–2569) ที่มุมขวาบนของการ์ด ระบบคำนวณใหม่ให้อัตโนมัติ (หรือกด "คำนวณตัวชี้วัด" เอง)
  - ระบบดึงข้อมูลรายหน่วยบริการจากตารางต้นทางของแต่ละตัวชี้วัดผ่าน Open Data API แล้วรวมเป็นร้อยละ (A ÷ B × 100) พร้อมแยกรายอำเภอและส่งออก CSV
  - ปุ่ม **รายละเอียดรายอำเภอ** เปิดตารางแยกตามอำเภอ คลิกแถวเพื่อเจาะลงตำบลและหน่วยบริการ มีสวิตช์แสดงทุกคอลัมน์ย่อย (หัวคอลัมน์ใช้คำอธิบายภาษาไทยจากโครงสร้างตาราง) และส่งออก CSV ตามระดับที่เปิดอยู่
  - **พิมพ์ / PDF สรุป 1 หน้า A4:** ปุ่ม "พิมพ์ / PDF" ที่หัวการ์ด สร้างรายงานแนวตั้ง 1 หน้า ประกอบด้วยตารางร้อยละรายอำเภอ × 13 ตัวชี้วัด (ลงสีตามเป้า) ตารางสรุปตัวชี้วัด (ผลงาน/เป้าหมาย/สถานะ) วันที่ประมวลผลข้อมูล และหมายเหตุสูตร จากนั้นเลือกเครื่องพิมพ์ "บันทึกเป็น PDF" ในหน้าต่างพิมพ์ของเบราว์เซอร์ (แนะนำเปิดตัวเลือก "กราฟิกพื้นหลัง" ถ้าสีไม่ขึ้น) ถ้าเปิดหน้า "แนวโน้มทั้ง 13 ข้อ" ไว้ก่อน จะมีคอลัมน์เทียบปีก่อนเพิ่มให้
  - **แนวโน้มทั้ง 13 ข้อในหน้าเดียว:** ปุ่ม "แนวโน้มทั้ง 13 ข้อ" ที่หัวการ์ด แสดงตาราง heatmap (ตัวชี้วัด × 5 ปี สีตามเป้าหมาย พร้อมการเปลี่ยนแปลงจากปีก่อน) และกราฟเส้นย่อยของทุกข้อ ส่งออก CSV ได้ ใช้เวลาดึงข้อมูลราว 30 วินาทีครั้งแรก แล้วแคชไว้ในหน้า
  - **แผนภูมิเปรียบเทียบรายอำเภอ:** ในแผง "รายอำเภอ" มีแผนภูมิแท่งแนวนอนเรียงตามผลงาน (หรือรหัสพื้นที่) สีแท่งตามสถานะเทียบเป้า มีเส้นเป้าหมายเป็นเส้นประ คลิกแท่งเพื่อเจาะลงตำบลและหน่วยบริการ แผนภูมิเปลี่ยนตามระดับที่เปิดอยู่
  - **เทียบเป้าหมาย:** การ์ดและตารางรายอำเภอลงสีเขียว/เหลือง/แดง (ผ่านเป้า / ใกล้เป้า = ถึง 90% ของเป้า / ต่ำกว่าเป้า) ค่าเป้าหมายตามที่กราฟของ HDC แสดง แก้ได้ที่ค่าคงที่ `NCD_TARGETS` ใน `index.html` (ข้อ 7 ยิ่งต่ำยิ่งดี, ข้อ 9 หน้า HDC ไม่ระบุเป้า จึงไม่ลงสี) หมายเหตุ: ค่า `target` ที่ API ของ HDC ส่งมาบางข้อต่างจากเป้าบนกราฟ (ข้อ 1, 2, 8, 12)
  - **แนวโน้ม 5 ปี:** ปุ่ม "แนวโน้ม 5 ปี" บนการ์ดดึงข้อมูลย้อนหลังและวาดกราฟเส้นเทียบเส้นเป้าหมาย พร้อมตารางการเปลี่ยนแปลงรายปี ปีเก่าที่ยังไม่มีคอลัมน์ `_13` (ข้อ 1, 8) ใช้ `target/result` แทน และมีเครื่องหมาย `*`
  - สูตรของแต่ละตัวชี้วัด (ตรวจเทียบกับหน้า HDC จังหวัดชัยภูมิ ปี 2569 แล้ว ยอดรวมตรงทั้ง 13 ข้อ):
    ข้อ 1, 8 ใช้ `result_13/target_13` · ข้อ 5 ใช้ `a1/b1` · ข้อ 6 ใช้ `(target−result)/target` · ข้อ 7 ใช้ `result_1/target_1` · ข้อ 9 ใช้ `(r1+r4+r5)/target` · ข้อ 10 ใช้ `result_bp1_d/target` · ข้ออื่นใช้ `result/target`
  - ข้อ 2–5, 7, 10 แสดงร้อยละของ "กลุ่มผู้มารับบริการ (CHRONICFU)" เป็นค่ารองด้วย
  - ชื่ออำเภอ ตำบล และหน่วยบริการ (รวม รพ.สต.) ดึงจาก API lookup ของ HDC ใช้ได้ทุกจังหวัด และเก็บแคชในเบราว์เซอร์ ถ้าโหลดชื่อไม่ได้จะแสดงเป็นรหัสแทน
  - ตัวเลขคำนวณจากข้อมูลเปิดเผย อาจต่างจากหน้า HDC เล็กน้อย ตรวจสอบกับต้นทางก่อนนำไปรายงานอย่างเป็นทางการ
- **ดึงข้อมูลรายงาน** เลือกตาราง ปี พ.ศ. (แสดงเฉพาะปีที่มีข้อมูลจริงของตารางนั้น) และจังหวัด (ล็อกเฉพาะ **ชัยภูมิ** ทั้งแอป หากต้องการเปิดให้เลือกครบ 77 จังหวัด ให้แก้ `const LOCK_PROVINCE = true;` เป็น `false` ใน `index.html`)
  - ตัวเลือกเพิ่มเติม: `limit`, `offset` และโหมดดึงทุกหน้าอัตโนมัติ
- **โครงสร้างตาราง** ชื่อคอลัมน์ ชนิดข้อมูล NULL ได้หรือไม่ และคำอธิบายภาษาไทย พร้อมคัดลอกเป็น `CREATE TABLE` หรือส่งออก CSV
- **ตารางข้อมูล** ค้นหา เรียงลำดับ แบ่งหน้า เอาเมาส์ชี้หัวคอลัมน์เพื่อดูคำอธิบาย
- **แผนภูมิ** สรุปความถี่ของค่าในคอลัมน์ที่เลือก
- **ส่งออก** CSV (รองรับภาษาไทยใน Excel) และ JSON
- **โค้ดตัวอย่าง** JavaScript, Node.js, PHP, Python, cURL ปรับตามค่าที่เลือกในฟอร์มอัตโนมัติ
- โหมดมืด/สว่าง และรองรับหน้าจอมือถือ

## วิธีใช้งาน

1. เปิด `index.html` ด้วย Chrome / Edge / Firefox (ต้องต่ออินเทอร์เน็ต)
2. เลือกรายงานจากการ์ดด้านล่าง หรือพิมพ์ชื่อตารางในช่อง `ตาราง` เช่น `s_ttm4`
3. เลือกปีและจังหวัด แล้วกด **ดึงข้อมูล**
4. ดูผลในแท็บ ตารางข้อมูล / โครงสร้างตาราง / แผนภูมิ / โค้ดตัวอย่าง

ลัด: กด `/` เพื่อพิมพ์ค้นหารายงานทันที

## เผยแพร่บน GitHub Pages

1. อัปโหลดไฟล์ `index.html` และ `README.md` ขึ้น repository
2. ไปที่ **Settings → Pages**
3. เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` และกด Save
4. รอสักครู่ จะได้ลิงก์รูปแบบ `https://<username>.github.io/<repository>/`

## API ที่เรียกใช้

| ใช้ทำอะไร | Method | Endpoint |
|---|---|---|
| รายการหมวดหมู่ย่อย | GET | `https://opendata.moph.go.th/opendata_api/reports/categories` |
| รายงานในหมวดย่อย | GET | `https://opendata.moph.go.th/opendata_api/reports/categorie/by-category-id/{cat_id}` |
| ปีที่มีข้อมูล | GET | `https://opendata.moph.go.th/api/report_year/{tableName}` |
| โครงสร้างตาราง | GET | `https://opendata.moph.go.th/api/report_schema/{tableName}` |
| ข้อมูลรายงาน | POST | `https://opendata.moph.go.th/api/report_data` |
| ชื่ออำเภอ / ตำบล (HDC) | GET | `https://api-hdc.moph.go.th/v1/lookup/district?provinceCode={จว.}` · `.../lookup/subdistrict?provinceCode={จว.}&districtCode={อำเภอ}` |
| ชื่อหน่วยบริการ (HDC) | GET | `https://api-center-hdc.moph.go.th/v1/system/hospital?provinceCode={จว.}` |

ตัวอย่างการดึงข้อมูล:

```bash
curl -X POST "https://opendata.moph.go.th/api/report_data" \
  -H "Content-Type: application/json" \
  -d '{"tableName":"s_ttm4","year":"2568","province":"36","type":"json"}'
```

## ข้อควรรู้

- **Rate limit:** API จำกัดจำนวนครั้งที่เรียกต่อช่วงเวลา (ตอบ HTTP 429 เมื่อถี่เกินไป) หน้าเว็บจะรอและลองใหม่ให้เอง การโหลดรายการครั้งแรกจึงใช้เวลาราวครึ่งนาที
- **แคช:** รายการรายงานถูกเก็บใน `localStorage` ของเบราว์เซอร์ ครั้งต่อไปเปิดได้ทันที ล้างข้อมูลเว็บไซต์ของเบราว์เซอร์เพื่อโหลดใหม่
- **CORS / เครือข่าย:** ถ้าดึงข้อมูลไม่ได้ หน้าเว็บจะแสดงข้อความผิดพลาดและปุ่มข้อมูลตัวอย่าง (Demo) ไว้ดูการทำงาน ข้อมูล Demo ไม่ใช่ข้อมูลจริง
- **พารามิเตอร์ต่างกันตามรายงาน:** ฟอร์มส่ง `tableName`, `year`, `province` เป็นหลัก บางรายงานอาจต้องการพารามิเตอร์อื่นหรือไม่มีข้อมูลในบางปี/จังหวัด
- **รายงานที่ปิดแล้ว:** บางรายการในแคตตาล็อกมีข้อความ "ปิดรายงาน" อาจดึงข้อมูลไม่ได้ ใช้สวิตช์ "ซ่อนรายงานที่ปิด" เพื่อกรองออก
